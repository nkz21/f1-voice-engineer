Installation rapide

  1. Cloner le repo 
    git clone https://github.com/nkz21/f1-voice-engineer.git
cd f1-voice-engineer
  2. Creer un venv et installer les dependances 
    python -m venv .venv
.venv\Scripts\activate
pip install -r app/requirements.txt
  3. Telecharger le modele Vosk FR

    Telecharger vosk-model-small-fr et mettre a jour VOSK_MODEL_PATH dans app/f1_assistant_vosk_ptt.py.

  4. Lancer l'application 
    python app/f1_assistant_vosk_ptt.py
