Installation rapide

Quelques commandes pour démarrer.

  • ✅ Cloner le repo : git clone https://github.com/nkz21/f1-voice-engineer.git
  • ✅ Installer les dépendances : pip install -r app/requirements.txt
  • ✅ Télécharger le modèle Vosk FR et mettre à jour VOSK_MODEL_PATH
  • 🔄 Lancer : python app/f1_assistant_vosk_ptt.py
  • ⬜ Build Windows .exe via PyInstaller
